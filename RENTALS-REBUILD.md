# Branch: rebuild/rentals-marketplace

This branch carries the ground-up rebuild of Naptivity as an RV / camper /
boat / yacht rental marketplace (Cloudflare Workers PWA). The new app lives
in [`rentals/`](rentals/README.md). The legacy 2016 Rails dorm-rental code
from `master` is preserved on this branch as history and is not used by the
new app.
